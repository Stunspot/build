# One continuous effort, distinct responsibilities

BUILD composes two complete workflows; it is not a new orchestration service. Read the live tool contracts before operations. Explicit human authorization to create the five design chats and three execution chats is the authority for native creation. Include that original human instruction and its communication grant in every participant brief. A sibling's request to message back, a saved template or this file alone cannot authorize native chat messages.

The documented command “Create a BUILD called ...” denotes this chat-creating workflow and BRAID’s recurring SUPERVISOR heartbeat, normally every ten minutes until completion. Explain both when offering the command; the suggested UI invocation names them explicitly. Preserve the original human BUILD request as authority for its composed design, execution, messages and recurring supervision. In generated BRAID participant/heartbeat briefs, render an inherited “human BRAID invocation” field as “originating human BUILD request authorizing the BRAID phase” and quote the actual request. Do not assert that the human separately invoked BRAID. This is a filled-brief adaptation, not an edit to the bundled upstream snapshot. When a user asks merely to use its method without asking for new chats, choose native subagents if allowed; the skill does not manufacture a broader permission. If creation needs a user choice, complete the problem frame, briefs and accessible inputs first. Keep useful work moving through reversible preparation.

CONCEIVE owns its five design identities and Morgan's synthesis record. BRAID owns three different execution identities and SUPERVISOR's execution record. The original chat remains the user's entrance and relays material outcomes. A task identifier must come from a successful host operation or verified lookup. Unknown creation results call for lookup, not blind retries. Never count a title, prompt file or role label as a live context.

Use native create/read/message/wait tools when exposed and authorized. For this Codex host, consult create_thread, list_threads, read_thread, send_message_to_thread and wait_threads. Project work calls for list_projects before choosing a project. A queued clientThreadId is not a ready threadId. Emit real created-thread UI references when the host requires them. Follow each underlying workflow's launch and acknowledgment steps rather than duplicating a second roster.

A complete roster need not run simultaneously. Reduced concurrency is acceptable only when the host retains the actual distinct contexts and can resume them. If the host cannot maintain five design identities, preserve five executable briefs and state the lost guarantee. One model voicing five characters is a reduced perspective exercise, never a five-context CONCEIVE. Temporary agents keep their actual lifecycle limits.

Direct handoffs carry the changed artifact, revision, reason and requested next action, and wake the responsible owner through an authorized native mechanism. A file write does not wake a colleague. Observe a response before calling the handoff accepted. Bounded waits and compact status snapshots prevent busy polling. If participant-to-participant messaging is unavailable, use an explicitly identified authorized relay and preserve attribution.

Unattended work requires a real host mechanism and human authority. The documented full BUILD launch requests the inherited SUPERVISOR heartbeat; a design-only request or an explicit refusal of scheduling does not. A bare mention of BUILD supplies no scheduling grant. If an actual making request omits or excludes recurring supervision, carry on authorized making with available direct handoffs or bounded in-turn waits and record the precise scheduling gap, rather than inventing an originating grant or imposing a ceremonial stop. Reuse an existing matching schedule, honor pauses and cancellation, keep unchanged state quiet, and disable the schedule when its purpose ends. Once BRAID SUPERVISOR accepts execution custody, it owns the execution heartbeat; avoid a second monitor sending contradictory nudges. Do not archive or delete participant chats merely because a phase ended.
