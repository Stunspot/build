# BUILD — authorship and source adaptation

Created by stunspot / Collaborative Dynamics.

BUILD composes CONCEIVE and BRAID without replacing either product’s governing responsibility. The package contains complete attributed workflow snapshots; their exact versions and source file identities appear in build/references/workflows/UPSTREAM.json. The author’s development refresh script owns updates to those snapshots.

The host supplies actual task identities, communication, artifacts and scheduling. This archive does not bundle a model, service, credential store or optional specialist skill. Product label artwork was created with an image-generation tool for this release.
