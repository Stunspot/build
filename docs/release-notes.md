# BUILD 0.1.0

**🏗️ Idea to finished work: CONCEIVE designs; BRAID makes and checks.**

BUILD is a free workflow skill by stunspot / Collaborative Dynamics. It carries an idea through five-context design into making, independent checking and supervision, preserving the reasons and constraints that make the result worth building.

## In this release

The complete package includes BUILD and attributed snapshots of **CONCEIVE** and **BRAID**, with role directives, templates, examples and recovery guidance. You can request either bundled workflow directly, use BUILD for the full journey, or carry a settled design straight into BRAID.

Codex is the targeted host. The host supplies models, tools, separate contexts, communication and scheduling; its account usage and costs still apply. The full named BUILD command requests five design chats, then three execution chats when ready, plus one recurring SUPERVISOR check normally every ten minutes until completion. Narrower instructions remain in force.

## Download and start

Download **BUILD-v0.1.0.zip** from this release, extract it, and follow its `INSTALL.md`. Keep the complete `build` folder together. Attaching a ZIP to a general chat is not permanent installation.

[Installation and first use](https://github.com/Stunspot/build/blob/main/docs/start.md) · [Choose a workflow](https://github.com/Stunspot/build/blob/main/docs/use.md) · [BUILD website](https://stunspot.github.io/build/)
