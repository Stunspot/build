# Evidence and limitations

[BUILD home](https://stunspot.github.io/build/) · [Install and start](start.md) · [Workflow guide](use.md)

BUILD 0.1.0 is a skill package of instructions, complete bundled workflows, role directives, templates and examples. Codex is its targeted host. It does not include a model, execution service, credential store, usage quota or optional specialist skill.

## What the release evidence supports

The release preparation checked package structure, metadata, local resource links, ZIP extraction parity and preservation of bundled upstream files. Three simulated discovery requests selected the intended routes: BRAID only, CONCEIVE only and full BUILD. These are bounded package and routing checks.

The workflow contract is source-verified in [BUILD](../package/build/SKILL.md), [CONCEIVE](../package/build/references/workflows/conceive/SKILL.md) and [BRAID](../package/build/references/workflows/braid/SKILL.md). The examples illustrate how the method should operate; they are not transcripts of successful customer runs.

## What has not been established

The release evidence does not establish a live five-context CONCEIVE launch, the composed native eight-chat journey, continuous unattended supervision, or successful execution on every customer host. It does not prove that more contexts make an answer more intelligent or that a particular cost or quality improvement will result.

Host tools, capacity, permissions, persistence and scheduling vary. A prepared brief is not an active participant; a saved handoff is not an acknowledged delivery; package checks are not an independent verdict on your finished work. Use the actual observed state when deciding whether to proceed.

The customer site is designed with semantic HTML, descriptive links, keyboard-operable native controls, reflow and text alternatives. Those authoring properties do not constitute a formal accessibility-conformance claim or representative-user research.

## Privacy and authority

Relevant context is shared across the collaborators your host creates. Its data handling and tool permissions govern that work. Include only appropriate material and keep credentials out of briefs. The static site adds no analytics, cookies, sign-in or remote font dependencies; downloads and support links take you to external services with their own policies.

The named workflow requests its described collaborators and supervision. It does not create blanket permission for spending, public publication, destructive changes or unrelated communication. Your specific instructions and the host's tool rules continue to apply.
